# Contributing

Keep this a short list of useful learning resources.

- Read the page before adding it. Prefer primary documentation, worked tutorials, and original research.
- Choose a descriptive title and name the author or publisher.
- Link directly to the lesson, not a homepage, pricing page, catalog, or search result.
- Remove redundant, misleading, obsolete, or inaccessible resources. A successful HTTP response alone is not a content review.
- Check version-specific instructions and distinguish vendor experience from general guarantees.
- List each resource once under Articles or Videos and update the README title to the unique article and video URL count. Table-of-contents and contributor links are not learning resources.
- Open every changed URL, then run `python3 scripts/check_resources.py`. CI checks the list's structure; it does not certify the truth of external content.

Linked material retains its authors' licenses. No public reuse license has been chosen for this repository's original text; the owner must choose one before public release or outside contributions.
